# StockMobile
App desenvolvido em linguagem DART com framework Flutter para aplicação do aprendizado realizado nas aulas do curso +MoreDevs2Blu realizado nos laboratórios do SENAC Blumenau- SC. Esse app esta sendo criado para mitigar problemas de estoque de produtos de insumos têxtil de uma facção que atende a marcas e lojas do Vale do Itajaí.
